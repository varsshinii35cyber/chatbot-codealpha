# FAQ Chatbot using NLP

## Project Description

This project implements an FAQ chatbot using Natural Language Processing.

The chatbot:
- Preprocesses text using NLP
- Converts questions into vectors
- Uses cosine similarity for matching
- Returns the most relevant answer

## Technologies Used

- Python
- NLTK
- SpaCy
- Scikit-learn
- Streamlit

## Features

- FAQ question answering
- Text preprocessing
- Similarity matching
- Interactive chatbot UI

## How to Run

Install requirements:

pip install -r requirements.txt

Run chatbot:

streamlit run chatbot.py

## Dataset

The dataset contains FAQ questions and answers related to the selected subject.
